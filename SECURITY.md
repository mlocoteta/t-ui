# Security and safety reports

- Please report vulnerabilities or safety problems privately via GitHub's "Report a vulnerability" (Security tab) rather
  than in a public issue.
- In scope: anything that could make the display show wrong driving information, hide an openpilot alert, send data off
  the device, or write to the comma without the user's explicit action.
- T-UI is read-only by default and collects nothing; there is no server and no account.
